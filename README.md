# Finger Chooser PWA

App web installabile come PWA su Android.

## Funzioni
- **Primo**: il primo tocco vince; il risultato resta congelato.
- **In ordine**: registra i tocchi in ordine progressivo.
- **A squadre**: assegna i partecipanti alle squadre in modo alternato, in base all'ordine dei tocchi (da 2 a 6 squadre).
- Pulsante **Ricomincia** manuale; nessun reset automatico.
- Interfaccia responsive, colori pastello, supporto multi-touch tramite Pointer Events.
- Service worker per uso offline dopo la prima visita.

## Pubblicazione
GitHub Pages: Settings → Pages → Deploy from a branch → branch `main`, cartella `/(root)`.
Apri l'URL HTTPS con Chrome su Android e scegli Installa app dal menu ⋮.
